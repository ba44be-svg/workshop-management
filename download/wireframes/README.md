## 📊 خلاصه صفحات

### ۱. داشبورد مدیر (`wf01_manager_dashboard.html`)
- ✅ ۴ KPI کلیدی: فروش امروز، پخش فعال، در انتظار تأیید، لات‌های نزدیک به انقضا
- ✅ نمودار فروش ۷ روز اخیر
- ✅ پیشنهاد انتقال FEFO (با تأیید همگی)
- ✅ صف تأیید مدیر (پیش‌نویس عامل + سفارش فروشگاه + انتقال)
- ✅ تب‌های اصلی: داشبورد، محصولات، تولید، پخش، حسابداری، کاربران، اعلان‌ها

### ۲. اپ موبایل عامل (`wf02_distributor_mobile.html`)
سه صفحه کلیدی نمایش داده شده:

| صفحه | شرح |
|------|------|
| ۱. سبد پخش امروز | لیست فروشگاه‌های اختصاص‌یافته با FAB + Barکدخوان |
| ۲. ثبت پیش‌نویس | فرم با ورود/اسکن بارکد، نمایش هشدار انقضا |
| ۳. وضعیت پیش‌نویس‌ها | Pending/Approved/Rejected با امکان اصلاح |

### ۳. پورتال فروشگاه PWA (`wf03_store_portal.html`)
سه صفحه کلیدی نمایش داده شده:

| صفحه | شرح |
|------|------|
| ۱. کاتالوگ + سبد | تصاویر محصول، Smart Reorder badge، سبد خرید |
| ۲. سفارش‌ها + اعلان‌ها | لیست سفارش‌ها با status + Push Notifications |
| ۳. پرداخت آنلاین | انتخاب مبلغ + انتخاب درگاه + منبع: زرین‌پال/آیدی‌پی/پارسیان |

## 🎯 اصول طراحی

### اصول مشترک
- **راست‌چین (RTL)** با فونت Vazirmatn
- **رنگ‌بندی**: آبی تیره (#1a365d) به‌عنوان رنگ اصلی، سبز (#2f855a) برای موفقیت، قرمز (#c53030) برای خطا
- **شدت رنگ**: اکثریت رنگ‌ها کم‌اشباع هستند (برای خوانایی بهتر)
- **استفاده ازアイکون‌های احساسی (Emojis)** برای شفافیت بصری سریع
- **تایپوگرافی**: ۴ سطح اندازه فونت (۱۱px، ۱۲px، ۱۳px، ۱۴px)

### اصول موبایل (React Native)
- **Bottom Navigation** با ۴ آیتم (خانه، پیش‌نویس، موجودی، پروفایل)
- **FAB** برای ثبت سریع پیش‌نویس
- **بارکدخوان Native** با `react-native-vision-camera`
- **حالت آفلاین**: Badge قرمز «آفلاین» با تعداد پیش‌نویس‌های Pending
- **Badge هشدار انقضا**: نمایش روزهای باقی‌مانده تا انقضا

### اصول پورتال (PWA)
- **Tab Navigation** افقی با ۵ تب (داشبورد، کاتالوگ، سفارش‌ها، پرداخت، گزارش)
- **Smart Reorder badge** روی محصولات پیشنهادی
- **Credit Limit Bar**: نمایش مانده، سقف و اعتبار باقی‌مانده
- **Payment Gateway Selection**: ۳ کارت با زرین‌پال به‌عنوان پیشنهادی
